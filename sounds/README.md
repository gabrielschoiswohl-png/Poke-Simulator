# Sounds

- `cries/`: Pokémon-Rufe von [PokeAPI/cries](https://github.com/PokeAPI/cries), als MP3 umgewandelt, damit sie am iPad laufen. Dateiname = Pokédex-Nummer.
- `kampf/`: Kampfmusik fürs Trainer-Duell, bei jedem Kampf zufällig eine. Neue Lieder hier ablegen und in `battleSongs` in der index.html eintragen.
- `heilen.mp3`, `level-up.mp3`, `sieg.mp3`: Effekte.
